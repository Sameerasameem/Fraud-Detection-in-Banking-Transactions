# Fraud Detection in Banking Transactions using MySQL

This project focuses on analyzing banking data using MySQL. It includes customer information,accounts, cards, transactions, loans, branches,
merchants, employees, beneficiaries, devices,and fraud alerts. It demonstrates database management, relational table connections, and
real-world banking data analysis.

## Database Tables
1. Customers
2. Accounts
3. Cards
4. Branches
5. Merchants
6. Devices
7. Beneficiaries
8. Employees
9. Fraud Alerts
10. Loans
11. Transaction Flag
12.Transactions

## Project Objectives
- Analyze customer banking details.
- Retrieve account and transaction information.
- Analyze loan details and outstanding amounts.
- Identify suspicious transactions and fraud alerts.
- Use joins, subqueries, aggregate functions,
  and grouping to analyze banking data.
- Generate meaningful insights using SQL queries.

## SQL Concepts Covered
- SELECT, WHERE, ORDER BY
- GROUP BY, HAVING
- INNER JOIN, LEFT JOIN
- Subqueries
- Aggregate functions
- DISTINCT
- CASE statements
- SQL triggers
